# 📱 Mobile Addiction Prediction

## 📌 Project Overview
Mobile phone addiction is a growing issue that impacts productivity, sleep quality, and mental health.  
This project predicts the **Mobile Addiction Level** of a user based on lifestyle and behavioral factors such as daily usage hours, sleep, exercise, anxiety, depression, and purpose of phone use.

---

## 🎯 Objectives
- Build a predictive model to estimate addiction levels.
- Identify key factors influencing mobile addiction.
- Provide an interactive web app for real‑time predictions.
- Generate insights to encourage healthier digital habits.

---

## 🛠️ Tech Stack
- **Programming Language**: Python  
- **Libraries**: Pandas, NumPy, scikit‑learn, Joblib  
- **Visualization**: Matplotlib, Seaborn  
- **Deployment**: Streamlit  
- **Version Control**: GitHub  

---

## 📊 Dataset
- Contains 18+ behavioral and lifestyle features.  
- Features include: Age, Gender, Daily Usage Hours, Sleep Hours, Exercise Hours, Anxiety Level, Depression Level, Phone Usage Purpose, etc.

### 📈 Insights
- Higher daily usage and screen time before bed increase addiction risk.
- Sleep and exercise reduce addiction levels.
- Social media and gaming drive higher addiction compared to education or family communication.
- Frequent phone checks per day are a strong indicator of addictive behavior.
